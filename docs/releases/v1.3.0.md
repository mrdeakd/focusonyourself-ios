# v1.3.0 — App Store Release

## What's New (App Store Copy)
<!-- Max 4000 characters. Plain text, localized. -->

This update brings guided meditation narration to your sessions. The meditation player now reads your session aloud using natural-sounding voice narration, with a seamless fallback to Apple's built-in text-to-speech when needed. Sessions also include a countdown timer so you always know how much time remains.

Under the hood, we've made significant performance improvements: faster date formatting, smarter caching, and a cleaner app structure for a smoother experience overall.
